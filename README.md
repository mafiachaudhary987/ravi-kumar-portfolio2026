# Ravi Kumar — Personal Portfolio

A responsive personal portfolio starter created for the YUGNEXT Web Development recruitment task.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Before submitting — personalise these details
- Confirm the display name (currently Ravi Kumar).
- Replace `YOUR_EMAIL@example.com` with your real email address.
- Replace `YOUR_GITHUB` and `YOUR_LINKEDIN` in `index.html` with your profile usernames/URLs.
- The skills section is written honestly for an HTML beginner. Keep it accurate as your skills grow.
- Replace the second project placeholder with a real project when available.
- Add real project links and screenshots if you have them.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Technologies
HTML5, CSS3 and vanilla JavaScript. Google Fonts (DM Sans and Space Grotesk) are loaded from Google Fonts.

## Deployment
The website is ready for static hosting (for example, GitHub Pages, Netlify or Vercel). A live hosted URL and a public GitHub repository are required by the recruitment brief; these still need to be created using your own accounts.

## Tools & AI note
ChatGPT was used to generate the initial page structure, CSS styling and a small JavaScript navigation script. The candidate currently knows HTML and is learning CSS and JavaScript. Review the files, personalise the content, test the website and be prepared to explain the parts you understand. Do not claim independent proficiency in technologies you have not learned.
